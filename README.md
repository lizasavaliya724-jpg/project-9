📊 Project 9 – Pandas Analyzer & Data Visualization

📌 Project Description

The Pandas Analyzer & Data Visualization project is a Python-based application used to analyze sales data and create different types of visualizations.

This project uses Pandas, NumPy, Matplotlib, and Seaborn libraries to perform data analysis, data manipulation, statistical calculations, and graphical representation.

It provides a menu-driven interface that allows users to perform different operations easily.

🎯 Objective

- To analyze sales data using Python.
- To perform data manipulation using Pandas.
- To perform mathematical operations using NumPy.
- To handle missing values in datasets.
- To calculate descriptive statistics.
- To create different types of charts and graphs.
- To understand Object-Oriented Programming (OOP).

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code

📂 Project Features

1. Load Dataset – Load sales data from a CSV file.
2. Explore Data – Display first rows, last rows, columns, and data types.
3. DataFrame Operations – Perform NumPy array conversion, indexing, slicing, and mathematical operations.
4. Handle Missing Data – Display, fill, drop, and replace missing values.
5. Descriptive Statistics – Calculate mean, median, standard deviation, variance, and percentiles.
6. Data Visualization – Generate different charts and graphs.
7. Save Visualization – Save charts as image files.
8. Exit – Close the program.

Step 4: Run the Python file.
